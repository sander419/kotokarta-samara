# kotokarta-samara — «Котокарта Самары»

Приложение из Google AI Studio: Vite + React + TypeScript (`src/App.tsx`, `components/`, `data/`).
Ключ Gemini — в `.env.local` (`GEMINI_API_KEY`), не печатать и не коммитить.

## Запуск и проверка
- `npm install`, `npm run dev` (порт 3000).
- Проверка правки: `npm run lint` (tsc) и `npm run build` без ошибок.

## Правила для агентов
- Где живёт прод — не записано; выкладку не делать без слова Саши.
- Одна задача — один агент в папке. Коммитить свои файлы по имени. Codex не пушит.
